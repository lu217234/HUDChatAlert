# HUDChatAlert

1.8.9 Forge Mod with Event HUD and Discord Webhook Integration alerts scraping Minecraft in-game chat strings.

### Usage
* **File Path:** `\Users\xxxx\AppData\Roaming\.minecraft\mods`
* **Default GUI Keybind:** `O`

### Sight/Integration Settings
* **Event HUD:** Toggle On/Off
* **Discord Webhook Usage:** Toggle On/Off
* **Webhook URL:** `YOUR_DISCORD_WEBHOOK_HERE`

### EventHUD GUI Settings
* **Scale +/-:** Changes EventHUD Size
* **Reset HUD Position:** Defaults EventHUD to Monitor Position 10, 10
* *EventHUD can be dragged inside GUI*

### Manage Event Alerts

<img width="483" height="551" alt="image" src="https://github.com/user-attachments/assets/93ff7be9-5573-4a0d-ba66-8084da0812fb" />

* **Chat Trigger Text:** `YOUR_DESIRED_SCRAPED_TEXT` *(example: `Envoys » An Envoy has spawned!`)*
* **Display Name:** `YOUR_DESIRED_DISPLAY_NAME` *(example: `&a&lEnvoy`)*
* **Item Icon:** Minecraft Item/Block Name *(example: `iron_sword`)*
* **Timer:** Time in Seconds *(example: `300`)*
* **Discord Message Content:** `YOUR_DESIRED_DISCORD_MESSAGE` *(example: `Envoy <@&1538048789699371028>`)*
* **Send Webhook:** YES/NO *(Disables/Enables Discord Integration)*
* **+Add New Alert:** Creates a new event Alert index
* **Delete Selected:** Deletes current event Alert index
* **< - >:** View `[<]` or `[>]` index
